# 契約を取り消せる？（keiyaku-torikeshi）

17歳のスマホの契約は取り消せる？だまされたら？いつまで？買い物や契約の場面を見て、民法の決まりどおりの答え（取り消せるか・だれが・いつまで・追認になるか）を選ぶ1日5問の学習ゲーム。正解したら「これは、どの決まり？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/keiyaku-torikeshi/>

- 答えは、e-Gov 法令検索の民法（<https://laws.e-gov.go.jp/law/129AC0000000089>）の行為能力・意思表示・取消しの条文（第3条の2〜第21条・第95条・第96条・第120〜126条。2026年6月24日施行の版を、2026年11月17日に読みました）で確かめたことだけです。
- 人の名前・年は作り話です。クーリング・オフ（特定商取引法）や消費者契約法の取消しは、このゲームでは答えにしません。民法の決まりだけです。いつ知ったかなど、一人ずつの事情の判断も答えにしません。
